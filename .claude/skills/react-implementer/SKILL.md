name: react-implementer
description: Legacy wrapper — now routes to 3 specialized agents: react-component-builder, react-infrastructure-engineer, react-api-integrator.
---

Use Skill tool to invoke `react-pipeline:subagent-dev`. Tasks are auto-routed to the appropriate specialized implementation agent:
- UI components/pages → `react-component-builder`
- Routing/state/types/config → `react-infrastructure-engineer`
- API client/data fetching → `react-api-integrator`
- Backend endpoints → `react-backend-engineer`
